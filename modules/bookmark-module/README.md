# 网址收藏合集模块 (bookmark-module)

> 版本：1.0.1 | 状态：✅ 功能完善

## 📌 模块简介

**网址收藏合集**是一个简洁高效的网址收藏管理模块，专为内网/团队共享场景设计。

### 核心特性

- ✅ **用户绑定**：每个网址记录创建者，只有创建者或管理员可以编辑/删除
- ✅ **隐私保护**：支持私密模式，私密网址只有创建者和管理员可见
- ✅ **智能搜索**：支持关键词搜索（标题）
- ✅ **卡片展示**：美观的卡片式布局，支持响应式设计
- ✅ **一键操作**：复制URL、新窗口打开
- ✅ **权限下沉**：模块内部自治，无需在主平台配置细粒度权限

## 🔗 API 接口

基础路径：`/api/v1/bookmarks`

### 1. 获取网址列表

**GET** `/api/v1/bookmarks`

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|:----:|:------:|------|
| page | Integer | ❌ | 1 | 页码 |
| pageSize | Integer | ❌ | 12 | 每页数量 |
| keyword | String | ❌ | - | 搜索关键词 |
| currentUser | String | ❌ | - | 当前用户名 |
| mineOnly | Boolean | ❌ | false | 只看我的 |

**响应：**
```json
{
  "code": 200,
  "data": {
    "records": [...],
    "total": 100,
    "size": 12
  }
}
```

### 2. 新增网址

**POST** `/api/v1/bookmarks`

```json
{
  "title": "Vue.js 官方文档",
  "url": "https://vuejs.org/",
  "description": "Vue3官方文档",
  "createdBy": "admin",
  "isPrivate": 0
}
```

### 3. 编辑网址

**PUT** `/api/v1/bookmarks/{id}`

**权限**：创建者或管理员

### 4. 删除网址

**DELETE** `/api/v1/bookmarks/{id}`

**权限**：创建者或管理员

### 5. 切换隐私状态

**PUT** `/api/v1/bookmarks/{id}/privacy`

**权限**：创建者或管理员

## 📝 权限说明

### 权限架构

本模块采用**权限下沉**设计：

| 权限类型 | 管理位置 | 说明 |
|---------|---------|------|
| 模块开关 | 主平台 | 启用/停用模块 |
| 细粒度权限 | 模块内部 | 创建者/管理员判断 |

### 模块内部权限规则

| 操作 | 普通用户 | 管理员 (SUPER_ADMIN) |
|------|---------|---------------------|
| 查看公开网址 | ✅ | ✅ |
| 查看私密网址 | 仅自己的 | ✅ 全部 |
| 添加网址 | ✅ | ✅ |
| 编辑网址 | 仅自己的 | ✅ 全部 |
| 删除网址 | 仅自己的 | ✅ 全部 |
| 切换隐私 | 仅自己的 | ✅ 全部 |

**无需在主平台配置 `bookmark-module:*` 权限**，模块会自动根据创建者和角色判断。

## 💡 设计理念

1. **极简主义**：功能精简到核心，减去不常用的排序、统计
2. **权限下沉**：模块自治，主平台只管开关
3. **移动优先**：响应式设计，移动端体验友好
4. **用户友好**：清晰的视觉反馈，完善的空状态提示
